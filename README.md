# Portfolio Website

A responsive static portfolio inspired by the reference site's dark editorial layout and lime accents. Includes a supplied profile photo, an interactive flip card, expandable project details, a live IST clock, scroll-in reveals, and active section navigation.

## Personalize it

Update `index.html` with your name, professional headline, location, bio, education, current status, skills, projects, and capability descriptions. Replace the sample profile URLs and email address. Update the photo alt text if needed. Project rows expand when clicked; replace titles, summaries, tools, and links with real projects.

The footer clock uses `Asia/Kolkata`; change the `timezone` value in `script.js` if needed. The image in `profile-photo.jpg` is the profile photo supplied for this portfolio.

## Run and publish

Open `index.html` in a browser. The site uses HTML, CSS, and vanilla JavaScript and requires no build step. Vercel is connected to this GitHub repository and deploys updates pushed to the main branch.
